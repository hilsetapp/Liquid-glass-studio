эффект «жидкого стекла» и выдаёт готовый CSS-код. Работает прямо в браузере.

**https://hilsetapp.github.io/liquid-glass-studio/**

## Часть 1. Открыть у себя на компьютере (30 секунд)

```bash
cd /home/user/liquid-glass-studio
```

И просто **открой файл `index.html`** — двойным кликом, как любой файл.
Всё, приложение работает. Не нужен ни npm, ни node, ни сервер.

(Если браузер по какой-то причине капризничает с локальными файлами,
запусти мини-сервер: `npx serve .` — и открой адрес, который он напишет.)

## Часть 2. Как пользоваться инструментом

Слева — панель настроек, справа — превью с цветными пятнами и панелью стекла.

| Ползунок | Что делает | Совет |
|---|---|---|
| **Blur** | Сила размытия фона за стеклом | 12–24px — «по-эппловски» |
| **Milkiness** | Насколько «молочное» стекло | 0.12–0.25 для тонкого эффекта |
| **Saturation boost** | Усиление цветов за стеклом | 140–180% — сочнее всего |
| **Corner radius** | Скругление углов | 20–28px современно |
| **Depth shadow** | Тень под панелью (глубина) | 24–48px |
| **Edge light** | Блик на кромке — секрет «стеклянности» | 0.5–0.8 |
| **Refraction** | Искривление света (эксперимент) | включи и потаскай панель! |

Дальше:
1. Тяни панель по экрану — смотри, как стекло реагирует на фон
2. Попробуй пресеты сверху или кнопку **🎲 Surprise me**
3. Загрузи свой фон (кнопка **Upload…**) — проверь на реальном контенте
4. Жми **Get the code ⚡** → вкладки **CSS** или **Tailwind** → **Copy**
5. Вставь в свой проект. Получившийся класс называется `.liquid-glass`

## Часть 3. Как сайт попал в интернет (и почему это бесплатно)

Используется **GitHub Pages** — бесплатный хостинг статических сайтов,
встроенный в GitHub. Схема такая:

```
ты пушишь код в main  →  GitHub Actions сам забирает файлы
                       →  сайт обновляется через ~1 минуту
```

Никаких серверов, никакой оплаты, ничего не нужно настраивать руками —
всё уже включено (включил я, через API, при публикации).

## Часть 4. Хочу что-то поменять в приложении

Весь код — 3 файла, написанных с комментариями:

```
index.html   ← что на странице (разметка)
styles.css   ← как страница выглядит (оформление самой студии)
app.js       ← как работает (состояние → CSS-эффект)
```

Порядок действий:
1. Поменяй файл (например, добавь пресет в `app.js` — массив `PRESETS`,
   просто скопируй один объект и поменяй цифры)
2. Открой `index.html` локально — проверь
3. Отправь на GitHub: `git add -A && git commit -m "..." && git push`
   *(если попросит авторизацию — скажи мне «запушь», сделаем за минуту)*
4. Через минуту сайт в интернете обновится сам

**Хорошие первые правки:** новый пресет, новые ползунки
(яркость блика, наклон панели), тёмная тема превью-фона.

## Часть 5. Частые вопросы

**Почему тут нет npm и node_modules?**
Потому что для браузерной страницы они не нужны. Три файла — всё приложение.
Это осознанный выбор: меньше слоёв — понятнее новичку и легче поддерживать.

**Эффект работает не во всех браузерах?**
Основа (`backdrop-filter`) — да, во всех современных. Преломление
(SVG-фильтр) — пока Safari и Chrome с экспериментальными функциями;
где не работает — показывается обычное матовое стекло, ничего не ломается.

**Можно ли использовать сгенерированный CSS в моих/коммерческих проектах?**
Да, лицензия MIT — без ограничений.

**Сайт долго грузится?**
Все файлы (включая картинки) лежат в репозитории — GitHub Pages отдаёт их
бесплатно и быстро. Если захочешь свой домен — это делается в настройках
репозитория (Settings → Pages → Custom domain).
