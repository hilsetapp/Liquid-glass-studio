# Короткий гайд по Liquid Glass Studio

Я собрал этот гайд по шагам. Для работы с инструментом не нужны опыт разработки, установка или сборка.

---

## Часть 0. Что это такое

Я сделал одну веб-страницу (`index.html` и файлы рядом), чтобы подбирать стеклянные эффекты и копировать CSS прямо из браузера.

Я опубликовал страницу здесь:
**https://hilsetapp.github.io/Liquid-glass-studio/**

---

## Часть 1. Открыть у себя на компьютере (30 секунд)

```bash
git clone https://github.com/hilsetapp/Liquid-glass-studio.git
cd Liquid-glass-studio
```

Открой `index.html` в браузере. Если локальная загрузка не работает, запусти `python3 -m http.server 8000` и перейди на `http://localhost:8000`.

---

## Часть 2. Как пользоваться инструментом

Слева находятся настройки, справа превью. Над превью я добавил три формы для проверки: Card, Button и Navigation.

| Ползунок | Что делает | Совет |
|---|---|---|
| **Blur** | Сила размытия фона за стеклом | 12-24px - умеренное размытие |
| **Milkiness** | Насколько «молочное» стекло | 0.12-0.25 для лёгкого оттенка |
| **Saturation boost** | Усиление цветов за стеклом | 140-180% усиливает цвета |
| **Corner radius** | Скругление углов | 20-28px современно |
| **Depth shadow** | Тень под панелью (глубина) | 24-48px |
| **Edge light** | Яркость блика по кромке | 0.5-0.8 |
| **Refraction** | Искривление света (эксперимент) | включи и потаскай панель! |

Порядок работы:
1. Выбери Card, Button или Navigation и потаскай образец по превью.
2. Настрой ползунки вручную или начни с пресета.
3. Загрузи фон кнопкой **Upload…**, перетащи файл или вставь скриншот через **Ctrl+V**. Файл остаётся в браузере.
4. Нажми **Copy settings link**, чтобы поделиться настройками. Ссылка не включает изображение.
5. Нажми **Get the code ⚡** и выбери CSS, CSS variables, Tailwind или SVG filter.
6. Скопируй код и перенеси его в свой проект.

## Часть 3. Как сайт попал в интернет (и почему это бесплатно)

Используется **GitHub Pages** - бесплатный хостинг статических сайтов,
встроенный в GitHub. Схема такая:

```
ты пушишь код в main  →  GitHub Actions сам забирает файлы
                       →  сайт обновляется через ~1 минуту
```

Я настроил публикацию через GitHub Actions. После отправки изменений в `main` Pages собирает и публикует статические файлы.

**Адрес:** https://hilsetapp.github.io/Liquid-glass-studio/
(складывается так: `НИК.github.io` + `/` + `ИМЯ-РЕПОЗИТОРИЯ`)

## Часть 4. Хочу что-то поменять в приложении

Весь код - 3 файла, написанных с комментариями:

```
index.html   ← что на странице (разметка)
styles.css   ← как страница выглядит (оформление самой студии)
app.js       ← как работает (состояние → CSS-эффект)
```

Порядок действий:
1. Поменяй файл (например, добавь пресет в `app.js` - массив `PRESETS`,
   просто скопируй один объект и поменяй цифры)
2. Открой `index.html` локально - проверь
3. Отправь на GitHub: `git add -A && git commit -m "..." && git push`
   *(если попросит авторизацию - скажи мне «запушь», сделаем за минуту)*
4. Через минуту сайт в интернете обновится сам

**Идеи для правок:** дополнительные формы компонентов, настройки цветовой схемы и новые форматы экспорта.

## Часть 5. Частые вопросы

**Почему тут нет npm и node_modules?**
Потому что для браузерной страницы они не нужны. Три файла - всё приложение.
Я оставил страницу без сборщика, чтобы её было проще запускать и изменять.

**Что будет в браузере без `backdrop-filter`?**
В сгенерированном CSS есть запасной непрозрачный оттенок. SVG-преломление экспериментальное и может не работать в части браузеров.

**Можно ли использовать сгенерированный CSS в моих/коммерческих проектах?**
Да, лицензия MIT - без ограничений.

**Сайт долго грузится?**
Все файлы (включая картинки) лежат в репозитории - GitHub Pages отдаёт их
бесплатно и быстро. Если захочешь свой домен - это делается в настройках
репозитория (Settings → Pages → Custom domain).
